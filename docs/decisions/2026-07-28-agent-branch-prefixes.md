# 任务分支不绑定单一前缀（2026-07-28）

## 影响

- 之前：只有 `lane/` 开头的分支会被识别成任务；Codex 默认创建的 `codex/` 分支会被误报成可以直接连接 GitHub。
- 之后：只要当前分支不是项目明确的稳定分支，就按待收尾任务处理。

## 根因

BossCoding 自己的任务命令使用 `lane/`，状态和收尾因此把实现习惯误当成了产品事实。真实小白验收中，Codex 按自身默认规则创建 `codex/` 分支后，状态盘漏掉了本地收尾。

## 裁决

**用“是否为稳定分支”识别任务，不再要求任何特定分支前缀。**

## 被否决的方案

**「额外兼容 codex/」**：下一种 coding agent 仍可能使用 `feature/` 或 `fix/`，继续追加前缀只会重复事故。

## 不变量

1. 稳定分支永远不能作为待收尾任务运行 `finish`。
2. 若项目无法明确识别唯一稳定分支，必须停止收尾并让 AI 先确认，不能拿当前分支猜。
